## Slice R7a — Bắt đầu nhẹ nhàng, tập trung tùy chọn

### Root causes found in code

- In `app/today/today-screen.tsx`:
  ```ts
  focusItem = asked ?? (next?.state === "running" && minimized !== next.key ? next : null)
  ```
  The focus view **opens by itself** whenever the suggested task is running. `minimized` lives only in memory, so every reload, and every tab, opens it again. That explains screenshot 3, where it is open on `tab=tuan`.
- `FocusView` (`app/today/today-parts.tsx`) has three more problems:
  - It is `fixed inset-0`, so when an ancestor has a `transform` (for example the `.pop` animation), `fixed` is relative to that ancestor. That is the likely cause of the right-shifted overlay (screenshot 4).
  - The timer is `clock(elapsed)` in `text-6xl` inside a 270 px ring. Past one hour it overflows ("2:32:22").
  - The only way out is a button labelled "Thu nhỏ".
- R6c's big timer in Góc học tập's work panel also shows `mm:ss`.

### Behaviour

1. **No auto-open, ever.**
   - The focus view is shown only after the child taps an explicit button: "🎯 Tập trung", or the running chip, or "Mở màn tập trung".
   - Remember the open state for the current task in `sessionStorage` (key `focus-open`, value = task key), so a reload keeps it open *if the child had opened it*. Clear it when closed or when the task is no longer running.
   - Delete the `minimized` / auto logic.
2. **Start sheet** (`StartSheet`, new) appears after a successful `/api/tasks/start` from any start button (Hôm nay status card, R6d cards, Góc học tập work panel).
   - **Layout:** a bottom sheet on phones, a centred card on wide screens. `role="dialog"` with `aria-modal="false"` and `aria-labelledby` the title. It is **not** a full-screen cover; the page stays visible behind a light scrim (`bg-ink/20`). Esc or the scrim closes it. Focus moves into it on open and back to the start button on close.
   - **Content:**
     - Eyebrow: "Bắt đầu rồi ✓".
     - Title: `Mục tiêu nhỏ: {item.title}`.
     - Sub line:
       - timed task: `{subject} · ít nhất {N} phút{appLabel ? ` · trên ${appLabel}` : ""}`
       - homework: "Làm xong trong vở thì chụp ảnh nộp."
     - Optional calm breath: a 4 s softly expanding circle with "Hít vào… thở ra…", played **once**. Off under reduced motion, where it becomes a static circle.
     - Buttons:
       - primary `Mở {appLabel} ↗` when there is a deep link (opens a new tab and closes the sheet);
       - `🎯 Ngồi cùng màn tập trung` (opens the focus view);
       - `Để sau` (closes).
     - Homework has no deep link, so its primary button is `🎯 Ngồi cùng màn tập trung`.
   - It is shown once per start, never on reload.
3. **Running chip** (`RunningChip`, new):
   - **Where:** in the `/today` header, on every tab. Also on `/binh-yen` is optional and not required.
   - **Content:** `⏱ Đang làm {short title} · {minutesLabel}`. If more than one task is running, add ` · +1`. Tapping it opens the focus view for that task.
   - **Look:** soft pill on the header colour, ≥ 44 px, `aria-label="Đang làm {title}, {minutes}. Mở màn tập trung"`.
4. **Focus view redesign** (`FocusView` rewritten; it may move to `app/today/focus-view.tsx`):
   - **Rendering:** through a **portal** to `document.body` (`createPortal`), `fixed inset-0 z-50`. It must be centred whatever the ancestor transforms are.
   - **Background by voice:**
     - **scientist (An):** the current world's drawn backdrop and ambient layer, from `app/today/world-scene.tsx`. Export `Backdrop` and `Ambient`, plus a tiny `sceneKeyOf(worldKey)`. Draw them full-bleed with a soft dark gradient on top so white text reads, and keep the motion slow. If the world key is unknown (not loaded, or before migration 0013), fall back to the forest. The world key comes from the `WorldResponse` already fetched for the world card, when present. Do not add a new fetch just for the background; fall back to the forest.
     - **detective (Nguyên):** a warm paper background (`#F7F2E7`) with a light screentone dot pattern (`radial-gradient` as in the `.mp` CSS) and a thin ink frame. Text is ink on paper, in the comic style. This view is light, not dark.
   - **Timer: minutes only.**
     - `minutesLabel(ms)`: `< 1 phút` → "vừa bắt đầu"; `< 60` → "{m} phút"; otherwise "{h} giờ {mm} phút".
     - Ring progress = elapsed ÷ minimum for timed tasks. For homework, show a slow "breathing" ring with no progress.
     - Under the timer:
       - timed, not ready: `Còn khoảng {ceil(remaining min)} phút nữa là bấm Xong được`
       - timed, ready: `Đủ {N} phút rồi ✓ — làm xong thì bấm Xong`
       - homework: `đã làm {minutes}`
     - Never show seconds. The ring text must fit: max width = ring diameter − 40 px, with `text-4xl sm:text-5xl`.
   - **Motivation line:** one calm line per voice, chosen by `hash(task.key + localDate) % n` from `lib/today/focusLines.ts` (pure, at least 12 lines per voice). The copy is calm, not hype, and has no exclamation spam. For example:
     - scientist: "Nhà khoa học nào cũng bắt đầu bằng một bước nhỏ."
     - detective: "Từng manh mối một. Không cần vội."
   - **Exit:** a clear `← Về Hôm nay` (top-left). Esc does the same. Closing returns focus to the element that opened it. The label "Thu nhỏ" is removed.
   - **Actions stay as today:** open app ↗, files, proof / finish buttons with the same server routes and rules.
5. **Long-running check** (display only):
   - **When:** a running task's elapsed time ≥ max(120 min, 3 × minMinutes).
   - **Focus view:** the timer area is replaced by "Con vẫn đang làm “{title}” chứ?" with `[Vẫn đang làm]` and `[Xong rồi]`.
     - `Vẫn đang làm` hides the question for 60 min (`sessionStorage`).
     - `Xong rồi`: for a timed task that is ready, finish through `/api/tasks/finish`. For homework, open the proof flow (the existing `onProofOpen`). For a timed task that is not ready, this cannot happen.
   - **Chip:** shows "· hơn 2 giờ" instead of the minutes.
6. **Góc học tập (R6c):**
   - The work-panel big timer uses the same `minutesLabel` (no seconds).
   - The header toggle "🎯 Chế độ tập trung" is renamed **"Chỉ hiện bài này"** / **"Hiện cả danh sách"**, so it is not confused with the focus view. Its behaviour does not change.
7. **Copy:** the existing buttons "Đang làm · mở màn tập trung" and "Mở màn tập trung" become `🎯 Tập trung`.

## Slice R7c — Hồ sơ mật cho Nguyên

### Content safety (the first priority)

Nguyên is a teenager. The cards are gentle **psychoeducation**, framed as curiosity ("hồ sơ" / "manh mối"). They are not therapy. They are ruled by:

- **Language:**
  - No clinical or diagnostic words about her ("rối loạn", "bệnh", "triệu chứng", "điều trị").
  - No frightening statistics, no catastrophe framing, no "you should", no comparison with others.
  - No self-harm, suicide, eating, weight or body-image topics.
  - No real living people's mental-health stories.
- **Claims:**
  - Hedged honestly ("nghiên cứu cho thấy… có thể…").
  - Every card has a **source**: a peer-reviewed paper or a reputable body (APA, NIMH, NHS, Harvard Health, Greater Good Science Center, WHO, Britannica for history). Show it small under the card: "Nguồn: …".
  - The source list with links and dates goes in `docs/binh-yen/HO_SO_MAT.md`.
- **"Thử nhỏ"** (optional micro-action) is limited to gentle things:
  - a slow breath with a longer exhale;
  - naming the feeling;
  - 5-4-3-2-1 noticing;
  - writing one line;
  - a short walk or stretch.
  - Nothing involving cold, pain or sensory shock.
- **Topics** (5 × 8 = **40 cards** in the first pack):

  | Topic | What it covers | Example clues |
  |---|---|---|
  | 🧠 **Não bộ** | how the brain works | the alarm (amygdala) and false alarms; naming a feeling calms the alarm (affect labeling); the planning brain keeps growing into the twenties; sleep files memories; breathing out slowly signals safety |
  | 💬 **Cảm xúc** | what feelings are | feelings are signals, not orders; worry is the brain rehearsing; feelings rise and fall like waves; mixed feelings are normal |
  | 📜 **Lịch sử** | how people of the past calmed their minds | the Stoics' journals; tea and slow rituals; letters; old Vietnamese sayings about patience. Facts only, carefully sourced |
  | 👥 **Con người** | how people work | the spotlight effect (people notice us less than we think); kindness lifts mood; small talk matters; asking for help is normal |
  | 🌏 **Xã hội** | the world around her | time in nature; community and belonging; how rumours spread; why breaks help work |

- **Fit to the check-in:** each card lists the quads it suits (`quads: Quad[]`; empty means any).
  - red/blue cards are reassuring and body-calming.
  - yellow/green cards are about curiosity and savouring.
- **Gate:** merging the R7c PR is the parent's approval. The parent reads `docs/binh-yen/HO_SO_MAT.md` (every card in full, with sources) before merging. Suggest in the PR body: if Nguyên has a counsellor or therapist, ask them to look at the pack too.

### Behaviour

- **Where:** in the corner, detective voice only.
  - On the "Xong rồi" step, under the KHUNG 1 frame, add a **collapsed** card "📁 Mở hồ sơ mật hôm nay?". It does nothing until tapped.
  - When the visit was **red or blue**, the card appears only after the acknowledgement and the activity are done. That is already the case on the "Xong rồi" step, so no change is needed. Keep it low-key.
- **When opened:**
  - It shows the card for (today, the chosen quad, the topic). The default topic is the last one picked on this device (localStorage `dossier-topic`), otherwise 🧠.
  - Topic chips (5) switch the card.
  - Card layout: eyebrow "HỒ SƠ MẬT · {topic}", a clue-style title, a 2–4 sentence body, an optional "Thử nhỏ" line, and "Nguồn: …".
  - Buttons: `Cất vào sổ tay` (adds to the notebook) and `Đóng`.
- **Selection:** `dossierFor(localDate, quad, topic)` is pure and deterministic.
  - Filter by topic, then by quad fit; if the quad filter leaves fewer than 2 cards, use the whole topic.
  - Pick `dayIndex(localDate) % n`, where `dayIndex` is days since 2026-01-01.
  - The same card for the same day, quad and topic. It rotates daily.
- **Notebook ("Sổ tay thám tử"):**
  - Lives on this device: localStorage `dossier-notebook`, a JSON array of `{date, key}`, newest first, keeping at most 200, deduplicated by key.
  - Shown in the R7b aside for Nguyên, or, if R7b is not merged yet, as a collapsed card under "Lần ghé gần đây".
  - Lists saved cards by title. Tapping one opens it.
  - Label: "Sổ tay trên máy này". No count badge.
- **Child-only:** no server route, nothing stored on the server. Nothing is logged.

### Tests

- **Vitest:**
  - Content validation: 40 cards; 8 per topic; every card has a title, a body of 2–4 sentences (≤ 420 chars), and a non-empty source; keys are unique.
  - No forbidden words: a regex list over all text ("rối loạn", "bệnh", "triệu chứng", "tự tử", "tự hại", "cân nặng", "ăn kiêng", "nên phải"…).
  - `dossierFor`: deterministic; changes by day; respects the quad fit with a fallback.
  - Notebook read/write: dedupe, cap, broken JSON, missing `window`.
- **e2e (`e2e/r7c.spec.ts`):**
  - Nguyên (grade 9) checks in. "Xong rồi" shows "Mở hồ sơ mật hôm nay?"; open it, switch topic, save it, and see it in the notebook.
  - An's "Xong rồi" has no dossier card.
  - Restore everything in `finally`.

### Content process

- An independent fact-check agent then reviews every claim and source.
- Finally the UI agent builds the slice on top of that content.
